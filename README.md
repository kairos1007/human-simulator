# 人类模拟器 Human Simulator

让 NPC 活过来：从定义一个人开始。

现在的游戏 NPC 只会简单对话、把主角引向任务，他们是 NPC，不是这个世界的居民。这个项目想先把「人」定义清楚：他的底色、认知、记忆、状态、关系，以及他怎么做决定、怎么说话。等一个人像人了，再让两个人、一个家、一个小镇运行起来。

规则由我自己写，AI 只帮忙整理、检索和实现。整个过程都公开在这里，包括想法、卡住的地方和推翻过的决定。

## 现在在哪一步

**阶段一：定义一个人。** 还没有可运行的代码。现在按白皮书的层逐层写规则，用纸面推演来检验：在纸上手推一个人在某个情境下会怎么选，换一个输入再推一次。

| 阶段 | 做什么 |
| --- | --- |
| **一、定义一个人** ← 现在 | 逐层写规则，通过纸面推演 |
| 二、白皮书 v1 | 别人只读白皮书，就能手推出一个人的选择 |
| 三、运行一个人 | 第一个可运行版本 |
| 四、两个人 | 两个人的决定互为对方的处境 |
| 五、一个家、一个小镇 | 接入世界层 |

详细的原则和路线见[设计纲要](docs/design-outline.md)。

## 白皮书的层

| 层 | 回答什么 |
| --- | --- |
| 底色 | 先天的、变化最慢的部分：原始动机、立场、家庭和时代 |
| 认知 | 他知道什么、相信什么，怎么评价好坏 |
| 记忆 | 什么被记住，睡眠和梦怎样压缩它 |
| 状态 | 此刻的能量和情绪，怎样升降，怎样改变选择 |
| 关系 | 信任、冗余额度、社交余量 |
| 决策 | 各层输入怎样合成一个决定 |
| 表达 | 每句台词背后的逻辑 |
